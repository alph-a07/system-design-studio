# System Design Studio — Starter Learning Instance

This directory is a pre-configured **Learning Instance**. You can clone or copy this folder to jump straight into learning with any AI coding agent!

---

## 🚀 How to Use

1. Open this directory in your AI agent (Antigravity, Cursor, Claude Code, or Codex):
   ```bash
   cd examples/starter-learning-instance
   ```
2. Prompt your agent:
   > *"Let's continue our system design learning journey from where we left off."*
3. The agent reads `.system-design/CURSOR.md` in a single tool call, identifies the active topic (`Topic 1.1: TCP vs UDP`), and delivers the lesson as an interactive HTML artifact!
4. Inspect your diagnostics anytime with:
   ```bash
   python3 ../../skills/system-design-studio/scripts/sync-status.py .system-design
   ```
