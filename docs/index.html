How it works

Three phases turn your AI coding agent into a stateful systems tutor that retains progress across sessions and model switches. Duration and depth are on-demand per topic: explore or deep dive repeatedly at your own pace.

Phase 1

Repository Scaffolding

The scaffolding script installs the .system-design/ directory into your local repository. 100% local files; zero external cloud services or databases.

.system-design/manifest.json
Phase 2

Your progress lives in a file

CURSOR.md records the active topic, verified prerequisites, hardware invariants, and previous analogies. When your AI context resets, progress is preserved.

.system-design/CURSOR.md
Phase 3

Interactive HTML Lessons

The agent generates self-contained interactive HTML artifacts directly inside .system-design/lessons/ with failure simulators and packet visualizers.

.system-design/lessons/*.html

The four layers of CURSOR.md

File-backed state on disk outlasts ephemeral AI chat context windows.

1. activeFocus
Tracks topic ID, depth tier, and active mechanism group. Ensures the tutor stays on the active objective.
topicId: topic.0.1.tcp-vs-udp · depthLevel: physical-mechanics
2. causalAnchors
Records physical latency numbers and network boundaries verified during lessons.
"Cold TCP + TLS 1.3 (no 0-RTT): 3 round trips before first byte"
3. examplesTaken
Registry of system domains used (financial ledger, audio streaming) to maintain continuity without repeating analogies.
["financial-ledger-wal", "live-webrtc-audio"]
4. deferredQueue
Tracks tangent questions for upcoming clusters without breaking topic focus.
["QUIC connection migration across cellular handoffs"]

Install for your agent

Two-step setup: install the skill into your AI agent, then scaffold the learning instance in your repository.

Where to install: We recommend a dedicated learning repository (for example, mkdir ~/learning/system-design && cd ~/learning/system-design && git init). If you scaffold inside an existing work repository, add .system-design/ to your .gitignore so personal progress files stay out of team commits.
Target: Antigravity Plugin Engine + local .system-design/

Comparison

How persistent file-based tutoring compares to a plain conversational chat.

Dimension A plain AI chat System Design Studio
State Across Sessions Kept in conversational context window; lost when thread resets or model changes. Saved to CURSOR.md in Git; preserved across sessions and model switches.
Teaching Approach Text summaries and definitions generated per prompt. Step-by-step topic curriculum anchored in hardware latency numbers.
Delivery Artifacts Markdown codeblocks and text replies in chat. Standalone interactive HTML files with state and packet simulators in .system-design/lessons/.
