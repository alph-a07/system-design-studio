The Physical Realities of Distributed Systems

System design begins with the speed of light and hardware limits. All mechanisms in the studio derive from these physical costs.

Physical Operation Actual Latency Human Scale (1 CPU cycle = 1 sec) Architectural Consequence
L1 Cache Reference 0.5 ns 0.5 s CPU core bound
RAM Access (DDR5) 100 ns 1.7 min In-memory key-value lookups
NVMe SSD Random Read 10–50 μs 2.8–14 hours Requires LSM-tree sequential writes
Data Center Network RTT 500 μs 5.8 days Cost of single-datacenter quorum (Raft)
Transatlantic WAN RTT 80 ms 2.5 years Synchronous cross-region consensus is physically impossible for sub-10ms writes
