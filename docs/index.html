Operational Mechanism

How it works

Four phases turn your AI coding agent into a stateful systems tutor with unannounced defense gates that verify true mastery before advancing.

Phase 1 01 / SETUP

Repository Scaffolding

The scaffolding script installs the .system-design/ directory into your local repository. 100% local files; zero external cloud services or databases.

Target: .system-design/manifest.json
Phase 2 02 / STATE

Progress in Git

CURSOR.md records the active topic, verified prerequisites, hardware invariants, and previous analogies. When your AI context resets, progress is preserved.

Target: .system-design/CURSOR.md
Phase 3 03 / ARTIFACTS

Live Interactive Lessons

New topics are delivered strictly inside standalone interactive HTML artifacts with live simulators crafted per topic. Follow-up trade-off discussions happen inline in chat without lecture duplication.

Target: .system-design/lessons/*.html
Phase 4 04 / DEFENSE

The Sign-Off Gate

It won't let you move on until you can defend it. The interactive lesson explores mechanics but hides the tick-off scenario. Progress in CURSOR.md advances only after you defend real trade-offs in chat.

Rule: Unannounced Chat Defense

File-backed state on disk outlasts ephemeral AI chat context windows.

pin_drop Layer 01 • Execution Focus

1. activeFocus

topicId: topic.0.1.tcp-vs-udp • depthLevel: physical-mechanics
anchor Layer 02 • Invariant Rules

2. causalAnchors

Records physical latency numbers and network boundaries verified during lessons so subsequent prompts reason from concrete bounds. 

"Cold TCP + TLS 1.3 (no 0-RTT): 3 round trips before first byte"
history_edu Layer 03 • Analogy Registry

3. examplesTaken

Registry of system domains used (financial ledger, audio streaming) to maintain continuity without repeating outdated analogies. 

['financial-ledger-wal', 'live-webrtc-audio']
queue_play_next Layer 04 • Tangent Buffer

4. deferredQueue

Tracks tangent questions for upcoming clusters without breaking current topic focus. Processed only when foundation phase closes. 

['QUIC connection migration across cellular handoffs']
Quickstart Command

Install For Your Agent

Single 1-line setup: detects active coding agents and installs the verified skill ready to use in any chat.

Universal Shell Installer • Auto-Detects All Agents

  • › /sds-teach [topic] (deliver)
  • › /sds-discuss (defend cold)
  • › /sds-complete (sign off)
  • › /sds-projects (switch/list)
Agents execute scripts silently under the hood.
PHASE 04 edit_note

Synthesized Notes

In-Chat Skill Commands • Universal Across All Agents

Command Your Agent in Chat

Zero terminal commands during learning. Talk naturally to Claude Code, Cursor, Codex, or Antigravity—or use structured slash commands. The agent handles engine scripts silently under the hood.

TIP

Natural Language Fluency: You don't have to memorize slash syntax! Say "Teach me topic 0.1" or "Here is my defense of the partition scenario..." and your agent will execute the exact same state transitions.

Core Pedagogy & Defense

ACTIVE LEARNING

Controls the causal teaching loop, interactive artifacts, Socratic stress-testing, and defense-gated advancement.

/sds-teach [topic] Deliver Lesson

Renders interactive HTML simulator or Markdown diagram artifact. Prompts for your initial intuition or working hypothesis before exposing physical mechanics.

Natural: "Teach topic 0.1" "Next topic" ➔ render-lesson.py
/sds-discuss Socratic Dialectic

Stress-tests your hypothesis. For seniors, probes cold failure modes and latency bounds. For juniors, provides Socratic scaffolding questions without spoiling the unannounced gate.

Natural: "Here is my trade-off defense..." ➔ Dialectic Engine
/sds-complete [evidence] Sign-Off Gate

Verifies cold trade-off defense against hidden gate in CURRICULUM.md. Upon passing: ticks topic, writes ADR in DECISIONS.md, advances CURSOR.md, and compiles active-learning study note.

Natural: "Mark complete" "Sign off topic" ➔ advance-cursor.py
/sds-status Progress & State

Inspects active topic, verified prerequisites, completion percentage, cognitive anchors, and deferred questions directly from disk.

Natural: "Show progress" "Where are we?" ➔ sync-status.py
folder_shared

Knowledge, Projects & Settings

STATE MANAGEMENT

Lists synthesized active-learning notes, switches workspaces, customizes curricula, and fine-tunes settings.

/sds-notes [topic] Study Notes

Lists all synthesized active-learning study notes for your project with clickable file:/// links. Formatted by your configured mode (atomic, cluster, tier, single-file).

Natural: "Show my notes" "Open notes" ➔ manage-projects.py notes
/sds-projects /sds-open <id>

Multi-project instances on one machine. /sds-projects lists all registered instances and track progress. /sds-open <id> immediately switches active context.

Natural: "List projects" "Switch to project distributed-lab" ➔ manage-projects.py
/sds-curriculum Customize Syllabus

Restructure cluster priorities, prune topics, or import a custom Markdown syllabus adhering to the 3-level taxonomy (Tier > Cluster > Topic) with gate validation.

Natural: "Customize syllabus" "Import BYO syllabus" ➔ configure-curriculum.py
/sds-config /sds-update

/sds-config [k] [v] updates visual theme, HTML vs. MD output, or note structure dynamically. /sds-update checks for new releases on-demand without background telemetry.

Natural: "Switch theme to obsidian" "Check for updates" ➔ merge-settings.py

Design Contrast

Comparison

How persistent file-based tutoring compares to a plain conversational chat.

Dimension A Plain AI Chat System Design Studio
Advancement Gate Nod-along agreement with no verification; advances whenever asked. The Sign-Off Gate: Lesson hides tick-off scenario; won't advance until you defend trade-offs in chat.
State Across Sessions Kept in conversational context window; lost when thread resets or model changes. Saved to CURSOR.md in Git; preserved across sessions and model switches.
Teaching Approach Text summaries and definitions generated per prompt. Step-by-step topic curriculum anchored in hardware latency numbers.
Delivery Artifacts Markdown codeblocks and text replies in chat. Standalone interactive HTML files with state and packet simulators in .system-design/lessons/.
Decision Records Ephemeral reasoning lost when context window rolls over. Logs your defenses into DECISIONS.md as an interview-ready ADR portfolio.
Example Tracking No record of previous analogies or examples across sessions. Logged in examplesTaken within CURSOR.md to avoid repeating scenarios.
Curriculum Scope & Teams Ad-hoc question answering with no shared curriculum across team members. Indexed 50 clusters in CURRICULUM.md; supports custom company stacks for onboarding.
