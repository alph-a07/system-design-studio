The four layers of CURSOR.md

Why plain-text Git state outlasts ephemeral AI chat context windows.

1. activeFocus
Tracks the exact topic ID, depth tier, prerequisites verified, and current mastery milestone. Ensures the tutor never wanders without clear goal completion.
topicId: topic.0.1.tcp-vs-udp · depthLevel: physical-mechanics
2. causalAnchors
Records non-negotiable physical laws and latency boundaries that the agent must hold the learner accountable to in subsequent architectural reviews.
"WAN RTT = 3 round trips before first byte on cold TCP+TLS"
3. examplesTaken
A deduplication registry of real-world metaphors and systems analogies already used. Prevents the AI tutor from repeating generic analogies across sessions.
["postal-packet-delivery", "airport-security-handshake"]
4. deferredQueue
Captures tangential topics, deep-dive rabbit holes, and edge cases discovered during discussion so they can be explored methodically without derailing focus.
["QUIC connection migration across cellular handoffs"]
